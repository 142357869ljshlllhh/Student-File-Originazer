# 大学生文件自动整理工具（SFO）

一个基于 Bash 的 Linux 文件整理项目，面向大学生日常学习资料管理场景，提供文件分类、重复文件检测、文件命名规范、空间统计、备份恢复和文件搜索等功能。

## 项目简介

在日常学习过程中，下载目录、桌面目录中常常混杂着课件、代码、图片、压缩包等各类文件。随着时间推移，容易出现以下问题：

- 文件类型混乱，查找困难
- 重复文件堆积，占用磁盘空间
- 图片或截图文件命名不规范
- 不清楚不同类型文件的空间占用情况
- 文件整理前缺少安全备份

本项目通过 Shell 脚本实现常见文件整理功能，适合作为 Linux 系统与 Shell 编程课程项目，也适合用于命令行文件管理演示。

## 已实现功能

### 1. 文件智能分类

按照文件后缀自动归类文件，例如：

- 课件资料
- 代码文件
- 图片文件
- 压缩文件
- 视频文件
- 音乐文件
- 其他文件

### 2. 重复文件检测

基于 `md5sum` 计算文件哈希值，检测内容相同的重复文件，并生成检测报告。

### 3. 文件命名规范

对符合 `IMG_` 命名格式的图片文件进行规范化命名，提升文件可读性。

### 4. 空间使用统计

统计磁盘使用情况和整理目录中各类文件的数量与空间占用。

### 5. 安全备份与恢复

支持在整理前创建备份，便于误操作后的恢复。

### 6. 文件搜索

支持按名称、类型、大小、时间等条件搜索文件。

## 主要模块说明

### `sfo.sh`

主入口脚本，负责：

- 启动交互菜单
- 解析命令行参数
- 调用各功能模块

### `config.sh`

配置文件，定义：

- 目标目录
- 分类目录
- 文件类型映射
- 阈值参数
- 备份与日志设置

### `modules/utils.sh`

公共函数库，提供：

- 目录初始化
- 日志记录
- 彩色输出
- 文件大小转换
- 依赖检查
- 文件移动辅助函数

### `modules/classify.sh`

实现文件分类逻辑，根据扩展名将文件移动到对应目录。

### `modules/duplicate.sh`

实现重复文件检测，并生成重复文件分析报告。

### `modules/rename.sh`

实现图片类文件的命名规范化处理。

### `modules/search.sh`

实现文件搜索与索引构建功能。

### `modules/stats.sh`

实现空间使用分析和统计报告输出。

### `modules/backup.sh`

实现备份、恢复、快照和旧备份清理功能。
